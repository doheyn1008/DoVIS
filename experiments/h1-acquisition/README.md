# H1 개발용 대화·외국어 이해 업데이트

확보한 H1 그림 세계 학습자를 실제 PNG와 상대가 생성한 발화에 연결하는 **개발용 절차 검사**입니다. 원래42개 `mutual_lab` 소스, native/acquisition 로더와 개발 체크포인트의 연구 입장 차단을 바꾸지 않습니다. 실제 자연어 코퍼스 모델의 학습과도 별도입니다.

`docs/candidate-freeze.md`는 H1 후보와 향후 보호된 모국어 평가의 입장 정책을 고정합니다. 보호 평가의 점수나 PNG를 열지 않으며, 기존 개발 체크포인트를 연구용 모국어 상태로 재분류하지 않습니다. 보호 평가 게이트 자체의 구현·실행은 이번 단계에 포함하지 않습니다.

`configs/development-smoke.json`은 한국어/일본어 replica0의 고정 최종9600 가중치, 이미지 prior,32회 노출과 네 조건을 명시합니다. 두 생성기가 처음에 만든 발화 스트림을 고정하고, 같은 공유 그림에서 각자의 이해부만 새 Adam으로 업데이트합니다. 학습자는 PNG·실제 상대 발화·세 PNG 대안만 받으며 정답 문장이나 Scene 메타데이터는 받지 않습니다. 공유 그림을 정답 선택지로 하는 대조 학습 신호는 주어집니다. 고정 화자의 발화와 시각 경험을 연관시키는 실험이며 적응적인 되묻기·협상은 측정하지 않습니다.

네 조건은 정상 연결, 업데이트0회, 발화 슬롯 순열로 연결 섞기, H1 이해부 전체를 원래 초기값으로 되돌리기입니다. 섞기 조건은 텍스트와 PNG의 주변 분포를 유지하지만 텍스트 순서와 연결은 바꿉니다. 실제 생성 오류는 점수로 고치거나 걸러내지 않으며, 처리 불가능한 빈 발화 등은 원시 기록을 남기고 실패로 종료합니다. 네 조건 모두 같은 원본에서 시작하며 중간 최고점을 선택하지 않습니다.

평가는 노출0/8/16/32회에 own-language 네 문형, foreign-language 네 문형, 실제 고정 상대 발화를 분리합니다. 평가 문형은 학습에 들어가지 않습니다. 평가 그림은 이번 L2 노출에서 제외한 개발28쌍이지만 L1 개발에 이미 사용됐으므로 새로운 연구용 일반화 자료로 설명하지 않습니다. 사전 이해도는 실제로 측정하고,4지선다 우연 수준.25나 보정 정확도0을 억지로 맞추지 않습니다.

절차 통과 조건은 이해 가중치의 실제 변화, 생성기/시각 경로/고정 특징의 불변, 평가 중 상태 불변, 업데이트0회 대조와 aligned16→32회 저장·재개의 정확한 일치입니다. **외국어 정확도의 향상은 smoke 통과 조건이 아닙니다.** 한 초기화 블록·한 언어쌍의 결과로 언어 거리나 학습 속도 차이를 결론내리지 않습니다.

## 실행

CPU Torch·NumPy·Pillow와 원본 `DoVIS-L1-H1-12-validated-models.zip`이 필요합니다. 이 ZIP의 SHA와 내부 두 모델·prior·sidecar·blueprint를 확인한 뒤 새 출력 디렉터리에 필요한 파일만 풉니다. 다른 모델을 끼워 넣거나 원본을 덮어쓰지 않습니다.

```bash
python run_smoke.py --models-zip /path/to/DoVIS-L1-H1-12-validated-models.zip \
  --output /path/to/new-run --revision PREPARATION_COMMIT_40_HEX
```

실제 실행 전 계획과 구현을 GitHub에 고정하고 준비 커밋을 전달합니다. 보고서에는 계획·스트림·소스·원본 파일 해시, 네 조건의 학습 곡선, 원시 평가 행, 생성 오류, 모든 상태 검사를 남깁니다. 상태는 별도 `h1-development-acquisition-v1`/`h1-development-pair-acquisition-v1` 형식이며 기존 연구 로더가 읽는 native/acquisition 형식으로 저장하지 않습니다.

새 스냅샷의 복원 전에는 같은 허용 PNG 풀을 `warm()`해 각 캐시 텐서를 독립적으로 재구성해야 합니다. Adam 상태·순서·카운터·개인 RNG와 캐시를 검증해 복원합니다. 정확한 재개는 이번 CPU 수치 환경에서 확인하며, 다른 환경의 정규 특징 값이 비트 단위로 다르면 복원을 거부합니다. 쌍 체크포인트는 두 학습자를 한 tensor 파일에 담고, 해당 SHA의 sidecar가 게시된 경우에만 유효합니다. 새 저장의 실패로 이전 파일을 덮어쓰지 않습니다.

```bash
python -m unittest discover -s tests -v
```

CI는 작은 합성 H1 체크포인트 fixture의 업데이트·동결·평가·저장/재개와 데이터/계획 경계를 검사합니다. 원본32회 예비 실험이나 보호 평가를 매 CI마다 다시 실행하지 않습니다.
