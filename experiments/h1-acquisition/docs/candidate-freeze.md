# H1 유한 그림 학습자의 후보 고정과 개발용 습득 절차

이 문서는 PR5의 코멘트6892339948에 따라 H1 후보를 고정하고, 기존 모국어 개발 모델을 외국어 이해 업데이트에 이식하는 범위를 정합니다. 현재 수행하는 것은 **개발용 절차 검사**입니다. 기존 체크포인트나 이번 출력의 `development_only`, `excluded_from_research=true`, `eligible_for_l2=false`, `eligible_for_fresh_experiment=false`를 유지합니다. 보호 모국어 평가나 정식 첫 접촉/L2 연구를 실행하는 승인 파일은 아닙니다.

## 고정 후보 h1-finite-scene-v1

H1은 무작위 초기화한 단일언어 GRU 학습자입니다. 모델당 전체477,443개, 학습364,675개 매개변수를 가지며, UTF-8 바이트259개 어휘, embedding64, hidden128, 한 층 GRU를 사용합니다. 이해 경로는 G1의 기본 GRU와 PNG 물체 attention을 함께 쓰고, 생성기는 F1의 물체 memory를 유지합니다. H1은 두34차원 물체 특징의 평균·y가중 평균·x가중 평균을 합친102차원에26개 고정0을 채워 정규화한128차원 벡터로 생성 GRU의 초기 상태와 매 token 입력을 조건화합니다.

지각 전처리는 단색 배경과 분리된 두 물체에 맞춰 직접 설계됐습니다. 물체별 연속 특징과 위치를 PNG에서 추출하며, 추론 시 정답 Scene이나 정답 문장을 생성기에 전달하지 않습니다. 이 구조가 일반 시각 지각이나 사람의 언어 습득을 구현했다고 해석하지 않습니다. 이미지 전용 Cprior는 모든 언어에 공유되므로 언어별 독립 시각 표상을 반복한 실험도 아닙니다.

학습 소스는 `b2be650797152e91b71ede62f3fe34adadbeb27d`, 실제 확인 실행은43674421396의 첫 attempt입니다. H1의 기존42개 package source 파일은 변경하지 않습니다. [고정 core source manifest](../configs/frozen-core-source-sha256.json)는 검토된 병합본 `3f48c73ccd971e92ff0d06c3240bc7334788c2c5`의 정확한42개 파일 이름과 SHA256을 고정하며, 실행 전 파일 집합과 각 바이트 해시를 검사합니다. 별도 adapter·runner와 그 소스 해시를 새로 기록합니다. 고정한 L1 자료 버전은 `five-colors-three-shapes-v1`이며5색·3도형·공간 관계, 네 이해 문형과 한 생성 훈련 문형입니다. 이미지 prior는55개 fit 물체쌍/220개 PNG만 사용했고, L1의 고정 최종 예산은9600회입니다. 최종 모델을 중간 최고점으로 바꾸거나 실패한 초기값만 교체하지 않습니다.

기존 archive SHA는 `78bee0bc13b8f91b414c42125020bf88f0d6a52362825ef0463a93afdb36fd16`, 공통 prior SHA는 `862eed3ec93a4567019075adcce59faf75295987a5cf6b816cace607da926e6d`입니다. 정확한 KO/JA replica0 최종 체크포인트·sidecar·config·prior 경로와 해시는 [개발 계획](../configs/development-smoke.json)에 있습니다. 원본 파일과 이미 봉인한 전체 이력 archive를 덮어쓰지 않습니다.

## 현재 개발 smoke의 고정 범위

KO/JA replica0의 초기화/학습 seed99007/99009, 최종9600 두 모델만 사용합니다. 두 모델을 고른 이유는 이번에 먼저 지정한 언어쌍·첫 replica라는 절차적 선택이며 성적을 비교해 고른 것이 아닙니다. 32회 공유 그림 노출을 수행하고0·8·16·32회에 평가합니다. `aligned`, `no_update`, `shuffled`, `reset_understanding` 네 조건은 같은 원본 PNG·실제 상대 발화·보기 스트림에서 시작하며, `shuffled`만 아래에 명시한 연결/발화 순서 변경을 적용합니다. 이 조건들을 모두 보고합니다. 그림 표집 seed119003, 평가 보기 seed119011, 혼합 연결 seed119031을 사용합니다. learner seed119021은 두 방향과 모든 조건에 공통인 private L2 RNG를 초기화하고, 각 업데이트의 보기 순서를 섞는 데 사용합니다. 원래 L1 초기화 seed99007을 바꾸는 seed가 아닙니다. 조건마다 fresh L2 Adam, learning rate0.001, 노출당 이해 업데이트1회를 사용하고 `no_update`만0회입니다. 이 작은 절차 검사에서는 native/foreign replay를 모두0으로 고정하며, 유지 성능을 높이려고 결과를 보고 replay나 학습 예산을 늘리지 않습니다.

두 모델이 같은 그림을 보고 모두 발화한 뒤 상대의 문자열과 PNG로 이해 경로만 업데이트합니다. 학습 입력은 **실제로 생성한 상대 발화**이며, 잘못된 발화도 정답 caption으로 바꾸거나 제외하지 않습니다. 오류·종료·인코딩·특수 token·의미 일치 여부는 연구자 측 진단으로 별도 기록합니다. adapter가 처리할 수 없는 빈 문자열이나 잘못된 문자열은 raw stream을 보존하고 실행을 실패로 남기며, 그 문항만 제외하거나 정답 발화로 교체해 완료하지 않습니다. 문자열과 PNG의 혼합 조건은 seed119031로 고정한32개 상대 발화 slot의 derangement를 두 방향에 똑같이 적용합니다. 발화·그림의 주변 분포는 유지하지만 발화 순서와 그림-발화 연결은 달라진다는 점을 기록합니다. 우연한 표면/의미 충돌도 기록하며 점수에 따라 다시 뽑지 않습니다. 모든 노출의 양·문자/바이트 수·실제 업데이트 수를 조건별로 기록합니다.

노출 그림은 고정된 development fit scene 순서에서 `Random(119003).sample`로 중복 없이32개를 뽑습니다. 보기의 distractor는 같은 unordered fit 물체쌍의 다른 세 역할/공간 variant이며, 모두 기존 development fit55쌍 안에 있습니다. 평가는 기존 development dev28쌍의112개 그림을 사용합니다. 이 그림들은 **이번 L2 노출에서는 제외됐으나 이미 L1 개발·모델 선택에 사용한 자료**입니다. 새 연구용 보호 의미나 전역적으로 처음 본 의미로 부르지 않습니다. 원래22개 보호 물체쌍의 PNG와 native/pretest/curve/final 점수는 이번 실행에서 학습·모델 입력·평가에 사용하지 않습니다. 그 의미 ID로 분할 교집합을 거부하는 경계 검사는 보호 점수를 읽는 행위와 구분합니다.

상대 언어의 네 작성 문형에 대한 이해와 실제 고정 상대 생성문에 대한 이해를 따로 보고합니다. 작성 문형은 평가용이며 외국어 훈련 정답으로 제공하지 않습니다. 자기 언어 네 작성 문형에 대한 이해와 자기 언어 자유 생성도 함께 기록합니다. 고정 dev112개 전체의 원래 생성 trace를 한 번 기록하고, 각 조건 뒤 사전에 고정한 첫 세 dev 그림에서 실제 재생성을 대조합니다. 생성기/시각 tensor·캐시 hash를 매 곡선 평가에서 함께 확인하며, 소수 재생성 검사를 전체112개 재생성 검사라고 부르지 않습니다. 초기 이해도는 실제로 측정하며0으로 맞추거나 양수 baseline을 숨기지 않습니다. 네 보기의 우연 수준은0.25이고, 보정 점수를 추가한다면 `(p-0.25)/0.75`로 원시 정답률과 구분합니다.

이 smoke의 성공은 외국어 정답률 상승량이 아니라 다음 불변 조건으로 결정합니다. 업데이트를 켠 경우 실제 이해 tensor와 attention으로 gradient/변화가 전달되고, 생성기·시각 tensor는 동결돼야 합니다. 평가 전후 모델·optimizer·로컬 및 Torch RNG는 같아야 하며, 연속 실행과 같은 노출 stream의 저장/재개 실행이 정확히 일치해야 합니다. 실제 두 모델 통합 검사는 사전에 고정한 `aligned` 조건의16회 저장 상태를 복원해32회까지 진행하고 연속 실행과 대조합니다. 다른 세 조건에 이 통합 재개 검사를 수행한 것으로 설명하지 않습니다. `no_update`의 가중치는 그대로여야 하고 노출 counter만 증가합니다. 실패·중단·누락은 성공으로 표시하지 않습니다. 작은 단일 초기화 결과로 언어 거리나 KO/JA의 상대 습득 난이도를 주장하지 않습니다.

생성기가 고정돼 있으므로 현재 측정하는 것은 **고정 발화와 공유 장면을 통한 cross-situational grounding**입니다. 상대가 오해를 듣고 설명을 바꾸거나 되묻는 적응적 대화·accommodation은 구현하거나 측정했다고 하지 않습니다.

## 보호 모국어 평가를 열기 전의 별도 입장 조건

다음 규칙은 미래의 정식 이식에 필요한 사전 고정 정책입니다. 현재 코드에 그 gate가 구현되거나 실행됐다는 뜻이 아니며, 아래 항목을 갖춘 별도 요청 없이는 보호 평가를 열지 않습니다.

1. H1 후보의 source·지각 처리·tokenizer·자료/발화 정책·이미지 prior·학습 예산과 새 L1 초기값 목록을 고정합니다. 언어별로 새 무작위 L1 가중치·새 optimizer/RNG에서 시작하는 독립 확인 계획과 원시 자료/실행 manifest를 먼저 보존합니다. 기존 development 체크포인트의 label만 바꿔 연구용 native로 입장시키지 않습니다.
2. 모국어 qualification에는 원래 `native`로 예약한 partition만 사용합니다. `pretest`, `curve`, `final` partition을 모국어 부족분을 채우는 데 사용하지 않습니다. 그 partition들이 현재22개 보호 물체쌍에 함께 들어 있다는 이유로 합쳐 평가하지 않습니다. candidate·fit/dev·native·pretest·curve·final의 명시적 교집합 검사와 각 manifest 해시를 보호 결과를 읽기 전에 고정합니다.
3. 원래 native partition은3색 세계의 일부입니다. 따라서 그것만으로5색 전체 또는 일반 자연어 능력을 주장하지 않습니다. 주장하려는 색·도형·역할 범위와 native suite의 coverage가 맞는지 먼저 의미 구조만 검사합니다. 부족한 범위는 `indeterminate_coverage`로 차단합니다. 새 qualification 자료가 필요하면 별도 버전·분할·초기화 계획을 먼저 등록하며, 기존 보호 점수를 확인한 뒤 coverage·기준을 조정하지 않습니다.
4. 아래 여섯 점수와 진단 coverage를 **동일한 고정 최종 L1 checkpoint**에서 함께 판정합니다. 중간 최고점, 언어별 다른 예산, 성공한 seed의 사후 합치기를 허용하지 않습니다. 정해진 네 언어×세 독립 초기화 블록의 모든 cell이 완전해야 하며, 한 cell의 실패·중단·누락도 보존합니다. 이 정책의 문서 고정이 현재12개 개발 모델의 연구 자격을 부여하지는 않습니다.

### 고정할 모국어 metric과 오류 처리

| 항목 | 계산과 분모 | 미래 native gate 기준 |
|---|---|---|
| 네 보기 이해 U | 예약 native scene의 네 작성 모국어 문형 각각에 대해 같은 물체쌍의 네 역할/공간 variant 중 정답 선택. 네 정답 위치를 균형화하며 전체 정답수/전체 예정 문항수 | 원시 정답률≥0.90 |
| 자유 생성 P | 예정 native scene별 greedy 생성1회. 해당 scene의 고정 문형 중 하나와 정확히 일치하고 EOS 종료·유효 UTF-8·본문 special token 부재를 모두 만족한 수/전체 예정 scene수 | 유효 생성률≥0.90 |
| 역할 반전 | 같은 축에서 subject/object만 뒤집은 의미를 가리는 이진 probe. 각 anchor의 네 작성 문형과 두 보기의 균형 위치를 고정 | 원시 정답률≥0.90 및 coverage |
| 색만 변경 | 물체 형태와 공간 축을 유지하고 한 물체의 색만 다른 이진 probe | 원시 정답률≥0.90 및 coverage |
| 도형만 변경 | 물체 색과 공간 축을 유지하고 한 물체의 도형만 다른 이진 probe | 원시 정답률≥0.90 및 coverage |
| 속성 결합 교환 | 서로 다른 두 색과 두 도형을 가진 anchor에서 도형 순서를 유지하고 색의 물체 결합만 교환한 이진 probe | 원시 정답률≥0.90 및 coverage |

각 이진 범주는 **최소8개 서로 다른 anchor와2개 서로 다른 unordered object pair**를 요구합니다. anchor와 counterfactual 모두 허용된 native qualification pool에 있어야 합니다. 이 숫자를 충족하지 못하면 점수를 보기 전에 coverage 미결정으로 차단하며, 다른 보호 partition이나 development 자료를 빌려 분모를 채우지 않습니다. 구조상 사용할 수 없는 anchor는 범주별 전체 수·사용 가능 수·서로 다른 쌍 수·정답 위치 수와 함께 남깁니다. 이진 우연 수준0.5와 보정 점수 `2p-1`은 원시0.90 판정과 혼동하지 않습니다.

자유 생성의 색·도형·역할 보존률도 고정 parser로 각 예정 scene을 분모로 계산해 따로 보고합니다. 해석 불가·의미 모호·미종료·잘못된 인코딩·본문 special token은 생성 gate에서 오답이며, 해당 속성 진단에서도 성공으로 세지 않습니다. 정답 단어를 포함했다는 이유만으로 속성·역할 성공으로 인정하지 않습니다. parser가 해석한 의미가 맞지만 고정 문형과 다르면 그 semantic lower-bound 진단을 별도 표시하고 유효 생성 gate를 소급 변경하지 않습니다. tolerance·정규화·동의어 목록을 보호 출력 확인 후 늘리지 않습니다.

비유한 logits/loss·예외·시간 초과·불완전 파일·평가 중 상태 변화는 해당 cell을 불완전/실패로 남깁니다. 실패한 문항만 분모에서 제거하지 않습니다. 모국어 gate를 통과하더라도 초기 상호이해도·정식 L2 노출·독립 최종 평가의 별도 사전 정책 없이는 L2 연구를 시작하지 않습니다. 앞으로 보호 결과를 보고 후보 구조나 자료를 바꾸면 같은 보호 집합을 재튜닝용으로 반복 사용하지 않고 새 개발 이력과 새 확인 계획을 만듭니다.
