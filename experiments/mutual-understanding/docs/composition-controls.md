# 모국어 조합 능력의 통제 비교

이 실험은 PR #3의 낮은 새 조합 생성 점수와 역할 뒤집힘 오류를 조사하는 개발 단계입니다. 모국어 적격성이나 언어별 외국어 습득 비용을 검증하는 본실험은 아닙니다. 모든 학습자 입력은 자기 언어 문장과 PNG이며 공개 언어·시각 가중치는 사용하지 않습니다.

## 학습 전에 고정하는 여섯 조건

| 조건 | 의미 분할 | 기본 모델 | 이해 인코더 | 생성 목표 |
|---|---|---|---|---|
| tiny_original_four | 기존 10/4쌍 | embedding32 / hidden64 | 단방향 마지막 상태 | 네 문형 |
| tiny_balanced_four | 상대 최소2종 10/4쌍 | 동일 tiny | 동일 | 네 문형 |
| medium_balanced_four | 상대 최소2종 | embedding64 / hidden128 | 단방향 마지막 상태 | 네 문형 |
| medium_balanced_one | 상대 최소2종 | 동일 medium | 동일 | 첫 문형 하나 |
| medium_balanced_bi_one | 상대 최소2종 | 동일 medium | 양방향 마지막 상태 | 첫 문형 하나 |
| medium_balanced_wide_one | 상대 최소2종 | 동일 medium | 폭을 늘린 단방향 | 첫 문형 하나 |

모델의 실제 매개변수 수는 tiny 87,491개, medium 281,219개, 양방향 372,099개, 폭 증가 대조군 372,499개입니다. 양방향과 폭 증가 대조군은 이해 매개변수 수를 가깝게 맞추며, 같은 medium 안의 생성기·시각 투영·입력 embedding 초기값은 같습니다. 양방향 인코더도 고정 길이 표현을 쓰므로 attention과 동등하다고 부르지 않습니다.

후보 관측 시점은 누적 1,200·2,400 step입니다. 여섯 조건은 각 언어의 동일 runner에서 순차 실행하며 한국어·일본어·영어·스페인어를 모두 보존합니다. 특정 언어 또는 시드가 잘 나온 조건만 남기지 않습니다. 이번 예산은 원인 비교용이며 이전 4,800-step 결과의 동일 수치 재현으로 해석하지 않습니다.

## 통제와 해석

- 기존 연구 TRAIN 내부에서만 분할합니다. 기존 분할과 최소2종 상대 분할을 모두 보존하고, 후자는 점수를 보기 전에 고정한 시드 순서의 첫 유효 분할입니다. 조건을 만족하는 후보가 14개 있습니다. 학습/개발 물체 쌍과 상대 수·해시를 기록합니다.
- 두 분할은 dev 물체 쌍도 달라집니다. 분할 정책의 비교이며 상대 수 하나의 인과 효과가 아닙니다.
- 이해 학습은 모든 조건에서 네 문형을 유지합니다. 한 문형 조건은 같은 배치의 같은 그림에서 생성 목표 문장만 첫 문형으로 교체합니다. 의미 표본 순서와 이해 문장 순서의 해시를 보존합니다.
- 이해와 생성의 gradient norm을 경로별로 각각 제한합니다. 기존의 전체 경로 공동 clipping과 다른 새 규칙이며 모든 비교 조건에 동일하게 적용합니다. 생성 목표 변경이 공동 clipping을 통해 이해 경로를 바꾸는 혼선을 피하기 위한 새 기준선입니다.
- medium은 언어 모델뿐 아니라 시각 투영 차원도 커집니다. 전체 프로파일 비교이며 순수 언어 용량 효과라고 부르지 않습니다. 같은 medium의 양방향/폭 증가 비교가 매개변수 수를 맞춘 인코더 대조입니다.
- 생성의 공통 성공 기준은 해당 의미의 네 원어 문형 중 하나와 일치하고 EOS·인코딩·특수 토큰 조건을 만족하는 것입니다. 한 문형 학습 조건에서도 동일합니다. 기존 teacher forcing 손실/토큰 정확도는 네 문형 모두에 대한 평가이므로 학습 목적과 같지 않습니다.

## 추가 이해 진단

기존 네 선택지는 같은 두 물체의 배치 변형이라 속성 구별을 독립적으로 측정하지 못했습니다. 새 진단은 기존 지표와 별도로 아래 두 그림 중 정답을 고르는 방식입니다.

- 같은 두 물체의 역할/방향 뒤집기
- 한 물체의 색만 변경
- 한 물체의 도형만 변경
- 두 물체 사이의 색·도형 결합 변경

버전은 `composition-binary-v1`, 선택지 수는2개, 우연 확률은0.5입니다. 기존4지선다 우연 확률0.25의 원점수와 직접 비교하지 않습니다. 모든 정답·오답은 연구 TRAIN에 속하고 선택지 안의 의미/PNG 중복을 검사합니다. 정답 위치를 범주별로 균형 배치하고 구성 불가능한 anchor는 누락 사유·가용 분모로 기록합니다.

기존 dev의 가용 anchor는 역할16·색16·도형12·결합12개이고, 상대 최소2종 dev는 역할16·색16·도형12·결합4개입니다. 각 anchor를 네 문형으로 평가하므로 이 문장들을 독립 반복으로 세지 않습니다. 특히 두 결합 지표는 평가 범위·분모가 다르므로 원점수 차이를 전체 결합 능력의 향상으로 단정하면 안 됩니다.

## 실행·보존·환경

```bash
cd experiments/mutual-understanding
python -m mutual_lab.composition_suite --language ja
python -m mutual_lab.composition_suite --aggregate-dir runs/composition-downloads --output runs/composition-summary.json
```

전용 `composition-controls.yml`에서 네 언어를 각각 실행합니다. 주 수치 의존성은 직전 실행에서 확인한 PyTorch2.15.0+cpu·NumPy2.5.4·Pillow12.3.0, Python3.12.16으로 고정합니다. 실제 전체 의존성 목록과 CPU·OS·Python·PyTorch 빌드 설정·스레드·결정성 설정을 추가 기록합니다. 동일 시드만으로 다른 환경의 비트 단위 재현성을 보장한다고 주장하지 않습니다.

각 조건은600초, 언어별 전체 비교는1,800초로 제한합니다. 완료·실패·시간 제한을 구분하고 모든 조건과 언어를 요약합니다. 모델·optimizer·난수 상태, 의미/문장 표본 순서, 원본 생성과 새 진단의 개별 예측은 개발 전용 파일로 저장해90일 artifact로 보존합니다. 평가 중 상태 불변성을 검사하고 기존 연구 로더가 개발 체크포인트를 거부하는 경계를 유지합니다.

이해와 자유 생성 각각90%라는 기존 개발 목표는 유지하지만, 이 목표를 넘는 것을 모국어 적격성이나 새 binary 진단의 통과로 자동 승격하지 않습니다. 보호된 모국어/사전검사/곡선/최종 평가는 계속 사용하지 않습니다.
