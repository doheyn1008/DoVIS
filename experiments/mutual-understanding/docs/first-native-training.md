# 첫 모국어 학습: 이해 경로 분리 진단

PR #1 병합 뒤 실제 CPU 가중치 학습을 시작하는 개발 실행입니다. 처음부터 무작위 초기화한 기존 GRU를 사용하고, 한국어와 스페인어는 각각 자기 언어 문장만 배웁니다. 공개 다국어 가중치·번역 모델·학습된 토크나이저를 사용하지 않습니다.

## 이번 실행의 질문

기존 개발 파일럿의 생성 100%·이해 37.5%는 별도 GRU 두 개의 결과였습니다. 먼저 이해 경로를 분리해 작은 자료를 배울 수 있는지 확인합니다. 한 물체 쌍의 네 장면을 대상으로 한 문형부터 학습한 뒤 같은 가중치로 네 문형을 추가합니다. 이 단계에서는 생성기를 훈련하지 않습니다.

학습·개발 자료는 모두 기존 연구 TRAIN 분할 안에서 고릅니다. 모국어 적격성, 첫 접촉 사전검사, 곡선, 최종 평가의 보호 분할은 사용하지 않습니다. 개발 점수는 언어 습득 비용이나 성인 수준 모국어 능력의 측정값이 아닙니다.

## 실행과 보존

`.github/workflows/first-native-training.yml`은 `codex/first-native-training` 브랜치의 관련 파일 변경에서 CPU 작업을 시작합니다. 한국어와 스페인어는 서로 독립된 작업으로 실행합니다. 각 학습 프로세스의 시간 상한은 10분이며 전체 작업 상한은 20분입니다. 기본 실행은 고정된 개발 시드와 예산을 사용하며 점수가 낮다고 시드를 바꾸어 재시도하지 않습니다.

```bash
cd experiments/mutual-understanding
python scripts/first_native_training.py --language ko
python scripts/first_native_training.py --language es
```

보고서에는 학습 곡선, 개별 예측, 문장 표현의 분산·유사도, embedding/GRU/head의 gradient 및 업데이트 크기를 남깁니다. 실제 가중치·optimizer·난수 상태도 개발 전용 체크포인트에 저장합니다. 체크포인트는 `native` 또는 `acquisition`이 아니며 본실험의 첫 접촉 모델로 로드할 수 없습니다. 생성기 미학습 상태와 `excluded_from_research=true`를 명시합니다.

실행 페이지의 `first-native-understanding-언어-실행번호` artifact에 보고서와 체크포인트를 함께 업로드합니다. GitHub 보관 기간은 90일입니다. 학습 실패나 시간 초과 때도 그때까지 작성한 자료의 업로드를 시도합니다.

## 다음 단계의 기준

이 작은 자료의 이해 학습 여부와 오류를 먼저 확인합니다. 성공하더라도 개발용 암기 확인이며 새 문장·새 물체에 대한 일반화 증거는 아닙니다. 낮은 점수도 그대로 보존합니다. 원인이 좁혀진 뒤 공통 모국어 훈련 예산·용량·자료 범위를 개발 자료에서 정하고, 별도 시드의 새로운 모국어 모델과 생성기를 훈련해야 합니다. 양방향 외국어 학습은 그 이후 단계입니다.
