# L1 속성 이해와 생성 후보 확보

이 개발 단계는 같은 두 물체의 배치만 구별하는 이해 점수와 실제 속성 이해를 구분하고, 새로운 물체 조합을 자기 언어로 설명하는 모델을 확보하기 위한 것입니다. 제한된 시각·문법 세계의 성공은 자연언어 전반의 모국어 숙련도나 외국어 습득 비용의 증명이 아닙니다.

## 고정 계획

`configs/mastery-plan.json`에 실행 전에 seed·예산·후보 풀·판정 규칙을 기록합니다. 이해는 네 문형, 생성 목표는 첫 문형 하나이며 모델은 embedding64/hidden128의 기존 단방향 GRU입니다. 원어 자료만 사용하고 이해/생성 gradient clipping을 분리합니다. 관측 시점은0/1,200/2,400 step입니다. 처리량은 별도20-step 실행으로 측정하고 실제 훈련 전 가중치·optimizer·난수를 복원합니다. 점수에 따라 예산이나 seed를 늘리지 않습니다.

### A: 학습 오답의 통제 비교

초기화/훈련 seed 쌍은 `(39007,39009)`, `(39017,39019)`, `(39027,39029)`로 고정합니다. 네 언어를 모두 실행하고 같은 언어의 A0/A1은 같은 runner에서 비교합니다.

- A0: 같은 두 물체의 배치 네 개를 선택지로 사용합니다.
- A1: 정답과 서로 다른 fit 오답 세 개를 사용합니다. 역할/색/도형/결합의 네 범주 중 하나를 교대로 생략하고, 가용 후보가 없으면 해당 fit 내부의 다른 고유 그림으로 채웁니다.

정답 anchor·문장·그림 표본 순서는 바꾸지 않습니다. 오답 RNG는 표본 RNG와 분리합니다. 생략 범주는 `(노출//4)%4`, 정답 위치는 `노출%4`라16노출 동안 범주와 위치가 균등 교차합니다. 부족한 범주 때문에 anchor를 제외하거나 dev에서 후보를 가져오지 않습니다.

학습 오답 함수는 전역 자료 대신 **fit 장면을 명시적으로 전달받습니다.** 기존 fit40장면의 가용성은 역할40·색20·도형20·결합8이며 색/도형이 모두 가능한 anchor는4개입니다. 후보 풀의 PNG/의미 해시, 중복, 실제 범주 노출과 fallback 수를 기록합니다. 두 조건의 최종 생성기와 의미/이해 문장 스트림 해시가 같아야 합니다.

### A 뒤 B의 정책 선택

최종2,400-step의 모든12개 언어×seed paired 비교가 완료되고 불변식이 통과해야 선택합니다. 네 속성 진단의 동등가중 macro 차이를 언어 평균→세 seed 블록 평균으로 계산합니다. 전체 차이가 양수, 세 seed 중 두 개 이상이 양수, 모든 언어의 기존4지선다 평균 하락이5%p 이내이면 A1을 사용하고 그 외에는 A0입니다. 누락·실패·불변식 위반은 선택 보류이며 B가 실행되면 사전 명시한 A0 fallback임을 원본 선택 요약과 함께 남깁니다. 이는 개발용 결정 규칙이며 유의성 검정이 아닙니다.

### B: 같은 공간 CNN의 이미지 사전학습 비교

개발 seed 한 쌍 `(39007,39009)`에서 네 언어 B0/B1을 실행합니다. CNN은3단계 stride convolution 뒤4×6 공간 grid를 flatten하여128차원으로 변환하며 위치를 없애는 전역 평균 pooling을 쓰지 않습니다.

- B0: seed49001로 초기화한 CNN을 그대로 고정합니다.
- B1: 정확히 같은 초기 CNN을 fit40개의 PNG만으로1,000 step 이미지 재구성 학습한 뒤 고정합니다.

이미지는48×32 RGB/255로 변환합니다. Scene JSON·속성 이름·문장·파일명은 시각 학습의 입력/목표가 아닙니다. dev/보호 그림은 정규화·조기 종료에도 사용하지 않습니다. 증강은 없고 각 PNG의 왼쪽 위 픽셀과 색 거리가0.02 넘는 부분을 전경으로 구분해 전경/배경 MSE를 각각 기록하고 동등 가중합니다. 표현 분산과 최소 그림 간 거리도 기록하되 의미 능력의 증거로 간주하지 않습니다.

언어 학습 동안 CNN의 파라미터와 buffer 해시가 모두 고정되어야 합니다. B0/B1의 언어 초기값·입력 순서·L1 정책·예산은 같으며 네 언어가 동일한 시각 prior를 공유합니다. 이는 prior에 조건부인 언어 비교이지 네 번의 독립 시각 반복이 아닙니다. 기존 무작위 투영과 CNN의 차이는 전체 시각 구조 비교이고 B0/B1이 이미지 사전학습 효과의 대조입니다.

## 후보 판정과 자료 한계

기존 이해·유효 자유 생성 각각90% 및 역할/색/도형/결합 진단 각각90%를 요구합니다. 각 진단에는 최소8개 서로 다른 anchor와2개 물체 쌍이 있어야 합니다. 점수와 가용성은 별도 필드로 보고합니다.

기존 balanced분할14개를 의미 조합으로 전수 확인하면 결합 진단은0개 또는4개 anchor만 있습니다. 따라서 A/B의 해당 판정은 구조적인 표본 부족으로 보류하며 점수에 맞춰 기준을 낮추지 않습니다. 같은 의미의 네 문형은 독립 반복이 아닙니다.

## 별도 C 자료의 사전 준비

이 구조적 가용성 제약 때문에 별도 버전 `five-colors-three-shapes-v1`의 개발 세계도 준비합니다. 실제 C 학습의 활성화와 사용할 모델/정책은 A/B의 남은 오류를 확인한 뒤 별도로 기록합니다. 자료를 준비한 것 자체가 개선을 뜻하지 않습니다.

노랑·보라를 추가해15개 물체·105개 쌍을 만들되, 기존 보호22쌍은 모두 제외합니다. 기존 fit10쌍은 새 fit에, 기존 dev4쌍은 새 dev에 그대로 남깁니다. 새로운69쌍을45/24로 나누어 fit55쌍·220장면과 dev28쌍·112장면으로 구성합니다. seed59003에서 점수를 보지 않는 첫 유효 분할은 index7이며 fit 최소 상대5종/dev 최소2종입니다. 새 dev의 결합 진단은60anchor·15물체쌍으로 최소 분모를 확보합니다. 기존 세계와 다른 모집단의 개발 실험으로 표시하고 원래 결과를 덮어쓰지 않습니다.

`configs/mastery-C-plan.json`은 초기화/훈련 seed `(59007,59009)`와 관측 예산2,400/4,800/9,600step을 미리 고정합니다. fit 문장이5.5배로 늘어난 데 따른 별도 예산이며 점수를 본 뒤 자동 연장하지 않습니다. 모델·학습 방식·후보 기준은 유지하고, C0/C1은 새 fit220PNG만으로 만든 같은 CNN의 무작위/재구성 사전학습 상태를 각각 고정합니다. 네 언어의 prior는 동일하며 B에서 공유 prior에 관해 한 독립성 제한도 같습니다.

C 실행은 별도 요청 파일로만 활성화합니다. 요청에는 A 원본 실행·소스 revision·선택 요약 SHA256·C 계획 SHA256과 선택된 정책을 고정하며 workflow가 실제 원본과 대조합니다. 준비 코드의 변경만으로 장시간 학습을 재시작하지 않습니다.

## 오류에 따른 다음 생성기 후보

`attentive_spatial.py`에는 조건부 D 후보만 준비되어 있습니다. 기존 GRU의 token hidden state가 고정 CNN의4×6공간 cell을 참조하는 생성 attention을 추가하고, 잔차 출력층을0으로 초기화해 첫 logits가 기존 생성기와 정확히 같도록 합니다. 기본 hidden128에서 추가 학습 파라미터는58,240개입니다. 같은 용량의 비교라고 부르지 않습니다. 이해기·시각 prior는 기존 경로를 유지합니다.

이 후보는 C의 실제 생성 오류가 해당 가설을 뒷받침할 때만 별도 실행 요청과 함께 활성화합니다. 새 자료와 생성기를 동시에 바꿔 단일 원인의 개선이라고 주장하지 않습니다. 생성 평가도 `teacher_forced_logits()`를 통해 실제 attention 경로를 사용하며 공간 grid를 빠뜨린 호출은 실패합니다.

`decoder_study.py`는 D0/D1의 원본 C 실행 보고서를 보존하고 별도 `decoder-study.json`으로 생성기 비교를 선언합니다. 두 조건은 동일한 고정 prior를 쓰므로 원본 C0/C1 표시는 자료·prior adapter일 뿐 D 조건명이 아닙니다. 초기 기본 생성기·이해기·prior가 같고, 최종 이해기가 그대로 같은지 검사합니다. 전용 요청은 원본 C prior manifest·실행·소스·계획의 해시를 고정합니다. 공통 prior를 재사용하며 C 언어 모델을 이어 학습하지 않습니다.

## 오류에 따른 오답 정책 후보

A1의 속성 진단 개선과 기존 이해 하락은 새 가설의 근거입니다. `mixed_blocks`는 기존 A0 문제16노출과 A1 문제16노출을 교대로 사용합니다. A1의 유효 노출 인덱스를 따로 계산해 각16노출 블록에서 기존 생략 범주×정답 위치의 완전 교차를 유지합니다. 완전32노출 주기에서 비율은50:50이며 A0 구간은 오답 RNG를 소비하지 않습니다. 기존 A0/A1 경로의 출력·노출 감사·난수 동작은 유지합니다.

`negative_policy_study.py`는 E0 `same_pair`와 E1 `mixed_blocks`를 비교하는 준비 도구입니다. C 자료·고정 시각 prior·고정 생성기 구조·seed·예산·정답/문장 스트림은 같고 오답 정책만 다릅니다. 초기 전체 가중치와 **최종 생성기 동일성**을 요구하고, 분기별 실제 노출과 모든 후보 기준을 기록합니다. 생성기를 고르는 D와 오답 정책을 고르는 E를 같은 원인의 변화로 합치지 않습니다. E도 별도 요청에 근거와 선택 모델/prior를 고정한 뒤 활성화하며 자동 승자 선택은 하지 않습니다.

## 학습 결과 직접 확인

`mastery_infer.py`는 개발 체크포인트와 그 원본 시각 prior를 불러와 PNG 설명 또는 선택지 이해를 시험하는 도구입니다. 체크포인트 sidecar의 해시·개발 전용 형식·관련 구현 소스·prior를 검사하며 `weights_only=True`로 읽습니다. 연구용 학습자 자격을 부여하지 않습니다. 결과와 함께 실제 언어·범위·종료/인코딩 상태를 출력하고, 추론이 가중치와 난수를 바꾸지 않았는지 확인합니다.

```bash
python -m mutual_lab.mastery_infer --checkpoint step-009600.pt --prior-bundle prior.pt --image scene.png
python -m mutual_lab.mastery_infer --checkpoint step-009600.pt --prior-bundle prior.pt --text 'The red circle is above the blue square.' --choices a.png b.png c.png d.png
```

학습 실행의 원본 revision을 사용하고 checkpoint와 같은 이름의 `.json` sidecar 및 원본 prior 파일을 함께 보존해야 합니다. 일반 사진이나 자유 대화 능력은 이 학습으로 검증되지 않았습니다.

## 실행·보존

```bash
python -m mutual_lab.mastery_lab --phase A --language ko --plan configs/mastery-plan.json
python -m mutual_lab.mastery_lab --phase B --language ko --plan configs/mastery-plan.json --policy attributes --prior-bundle prior.pt
```

전용 workflow는 계획 파일의 명시적 변경·실행 요청·수동 실행으로 시작하며 A→사전 정책 선택→B를 순서대로 실행합니다. 이미지 prior는 같은 fit만으로 A와 병렬 준비합니다. 모든 조건·seed·실패·시간 제한·취소를 보존하고 수정한 deadline/관측 보존 경계를 유지합니다. 주요 수치 의존성과 실제 환경을 기록하며 실제 가중치·optimizer·두 RNG·노출 감사·학습 곡선·개별 예측·원본 생성과 집계를30일 artifact로 저장합니다.

개발 체크포인트는 기존 연구 입력에서 역직렬화 전에 차단됩니다. 후보가 생겨도 설계를 동결하고 새로운 독립 seed에서 재검증한 뒤 보호된 모국어 평가 정책을 확정해야 합니다. 본실험이나 외국어 상호학습으로 자동 승격하지 않습니다.
