원본 E의 통제 실패는 그대로 보존합니다. 수정 E2 실행은 `43640297149`, F는 `43640297162`이며 소스는 모두 `12f4453d0e77e8e1c5cebc68cd54b9d3082194f6`입니다. 두 실행 모두 네 언어의 비교 학습을 9,600 step까지 완료했습니다. E2에서는 정책만 다른 두 조건의 최종 생성기 해시가 네 언어 모두 정확히 같고, F에서는 생성 memory만 다른 두 조건의 최종 이해기 해시가 모두 같습니다. 원래 E의 실패를 지우거나 성공으로 바꾸지 않습니다.

## G에서 바꾸는 것

G0는 기존 전역 그림 벡터와 문장 최종 상태의 점수를 유지합니다. G1은 동일한 문장 GRU의 유효 byte 상태가 PNG에서 추출한 순서 없는 두 물체 token을 읽어 잔차 점수를 더합니다. 처음에는 잔차 출력 가중치가 0이므로 G0와 이해 점수가 정확히 같습니다. 이후 점수 차이는 측정하며 역할 이해가 자동 보존된다고 가정하지 않습니다.

G1은 H128에서 이해 매개변수 25,216개를 추가합니다. 이는 **지각 정보·용량·이해 readout을 함께 바꾸는 개발 비교**입니다. attention 하나의 인과 효과나 단어 정렬을 입증하지 않습니다. 생성기 구조·초기 가중치·그림 memory·전역 CNN·학습 자료와 순서·오답 정책·최적화·시드는 두 조건에서 같습니다. 최종 생성기 가중치와 생산 경로의 고정 특징 표가 정확히 같아야 유효한 비교입니다.

기존 C 자료·보호쌍 22개 제외·55 fit/28 dev 쌍·59007/59009·2,400/4,800/9,600 step·원래 90% 기준과 진단 최소 8 anchor/2 pair를 유지합니다. 새 언어 가중치와 새 Adam에서 시작하며 F 언어 가중치를 이어받지 않습니다. 공통 이미지 전용 prior만 재사용합니다.

G 결과를 보기 전에 전체 후보 선택도 고정합니다. 네 언어가 각자 같은 최종 체크포인트에서 여섯 점수와 평가 범위를 모두 통과한 조건만 후보입니다. 후보가 둘이면 4언어×6점수의 최솟값이 높은 조건을 고르고, 정확히 동점이면 G0입니다. 후보가 없으면 선택하지 않습니다. 요청 파일은 F 요약·prior·계획·G 구현·복원 코드의 SHA256을 고정합니다.

G 등의 전체 후보가 생겨야 `cohort_validation`을 별도 요청으로 활성화합니다. 처음부터 정해둔 세 seed 쌍 `(69007,69009)`, `(69017,69019)`, `(69027,69029)`으로 네 언어씩 **12개 모델을 새로** 학습합니다. 각 블록은 언어 간 같은 초기화·의미 표본을 사용하며 블록 사이 언어 가중치와 Adam은 독립입니다. 선택한 구조·자료·예산·기준을 그대로 고정하고 후보를 다시 고르지 않습니다.

12개 모두 자신의 고정 최종 체크포인트에서 같은 여섯 목표와 진단 범위를 통과해야 반복된 개발 후보로 표시합니다. 공유한 이미지 prior까지 독립적으로 재학습한 반복은 아니며, 자동 연구 적격성이나 L2 실험 승격은 허용하지 않습니다. 실패·시간 초과·중단·불완전 요약도 남깁니다.
