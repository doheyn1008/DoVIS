# 연구 프로토콜과 해석 범위 (v2)

## 질문과 분석 단계

모국어를 충분히 배웠고 상대 언어 자료로 훈련된 이력이 없는 두 학습자가 공동 환경에서 자기 언어로 말할 때, **언어 쌍에 따라 상대 언어를 익히는 노출 비용이 달라지는가**를 묻는다. 공유 그림은 같은 환경을 보는 첫 만남의 추상화다. 그림 유무의 효과로 주제를 대체하지 않으며, 문자 입력으로 음성 기반 첫 접촉까지 재현했다고 하지 않는다.

1. 모국어 적격성과 단일언어 훈련 출처를 확인한 뒤, 별도 사전검사에서 **두 방향 모두 사전등록한 우연 수준 주변 구간에 포함되는 쌍**을 1차 분석 대상으로 삼는다.
2. 훈련 이력 없이 일부 이해되는 쌍은 양수 baseline 확장으로 남긴다. 모국어 지식을 지우거나 문항을 사후 선별해서 출발점을 맞추지 않는다. L1 이해 가중치 초기화는 별도의 대조 조건이다.
3. 언어 목록의 모든 서로 다른 쌍으로 확장하고 모델 조건별 방향성·안정성을 조사한다. `grid`는 모든 쌍을 실행하되 사전검사 분류와 부적격 사유를 보존한다. 언어 목록을 줄여 파일럿부터 진행할 수 있다.

측정값은 정해진 학습자·모국어 경험·시각 과제·학습 규칙·평가 척도 아래의 **방향성 있는 습득 비용**이다. 대칭성·삼각부등식·보편적 언어 거리·역사적 계통을 가정하지 않는다. 비용으로 척도를 정의한 뒤 빨리 배우는 언어가 가깝다는 순환논증으로 타당성을 검증하지 않는다.

## 실행 모드와 참가 조건

| 모드 | 학습 경로 | 본실험과의 관계 |
| --- | --- | --- |
| `demo` | 고정 템플릿 + 완전한 시각 특징 + 빈 naive Bayes 수신자 | 측정 장치 검사. 모국어 전이가 없는 기호학습 데모 |
| `endpoint` | 외부 VLM 고정 가중치 + 최근 기록 | 문맥 적응 파일럿. 단일언어 초기화·영구 학습을 증명하지 않음 |
| `neural` | 자기 언어로 훈련한 GRU 이해 모듈에 공유 그림·상대 발화로 계속 역전파 | 누적 학습 경로 검사. 적격성·초기 조건을 통과한 실행만 해당 분석 후보 |

영어·한국어·일본어·스페인어 자료는 각 4개 문형으로 작성한 제한된 자연어 문장이다. `languages.py`는 모두 `controlled-pilot` 상태로 표시한다. 자연어 전반의 완성된 자료나 일반적 모국어 숙련도를 뜻하지 않는다. 미지원 언어·구조·학습 프로파일은 실행 전에 거부한다.

모국어 훈련의 기본 통제는 **동일 optimizer step·batch 예산**이다. 학습 후 실제 능력이 같다고 가정하지 않는다. 각 모델의 실제 모국어 이해·생성 점수를 따로 저장하고, 같은 예산에서 적격성 기준을 못 넘은 모델도 제거하지 않고 사유와 함께 남긴다. 성취도 일치를 기본 조건으로 쓰려면 별도 사전등록 프로파일과 정지 규칙을 구현해야 한다. 현재 `budget_rule`은 `equal_steps`만 허용한다.

## 모국어 학습과 외국어 지식 감사

`train-native`는 시드별 같은 초기 가중치에서 언어별 모델을 만든다. 함수에 선택한 언어의 문장만 제공하며, 같은 의미 장면 범위를 사용한다. 학습 표본·순서는 모국어 훈련 시드로 정한다.

- 이해: 토큰 embedding → GRU → 정규화한 표현과 4개 그림 표현의 대조학습.
- 생성: 그림 표현을 조건으로 넣는 별도 autoregressive GRU. 자기 언어의 여러 표현과 역방향 문형을 teacher forcing으로 배운다.
- 시각 입력: PNG를 RGB 16×12로 pooling하고, 언어 자료 없이 생성한 초기 랜덤 투영을 고정한다. 파트너의 장면 의미 JSON·내부 표현·가중치를 받지 않는다.
- 외국어 이해는 **바로 그 L1 이해 모듈의 embedding·GRU·head**를 이어 쓴다. 별도의 빈 외국어 수신자를 붙이지 않는다.
- L1 생성기의 embedding·GRU·출력층은 만남 뒤 고정한다. 두 발화를 모두 만든 뒤 양쪽 이해 모듈을 업데이트한다. 질문·재설명·상호 발화 조절까지 구현한 조건으로 부르지 않는다.

다국어 사전학습 가중치·학습된 토크나이저·이미지–텍스트 사전학습을 내려받지 않는다. 기본 입력은 고정 숫자 대응의 UTF-8 바이트다. 민감도 조건 `unicode-bmp`는 사전에 정한 BMP 코드포인트 전체의 숫자 대응이며 자료로 vocabulary를 fitting하지 않는다. BMP 밖 문자는 거부한다. 문자 조건은 vocabulary 크기·실제 매개변수 수도 바뀌므로 같은 능력으로 조용히 합치지 않는다. UTF-8은 한글·일본어의 시퀀스를 더 길게 만들며, 동일 토큰 수는 동일 의미 경험이 아니다.

원본 native 체크포인트에는 모델 전체, 최초 이해 가중치, L1 optimizer·난수 상태·자기 언어 복습 자료를 저장한다. 별도 JSON sidecar에 SHA256, 언어·구조·토크나이저, 초기화/훈련 시드, 자료 해시, 실제 매개변수 수, 코드 revision, 훈련 언어 목록과 외국어 훈련 이력, 이해·생성 성취도와 적격성을 기록한다. 이는 이 코드가 생성한 제한된 자료의 provenance이며 임의 외부 모델의 이력을 자동 입증하지 않는다.

`metadata`의 훈련 언어 이력은 **원본 L1 훈련에만** 해당한다. 만남 후 체크포인트는 원본 L1 출처를 유지하면서 `kind="acquisition"`과 실제 optimizer·버퍼·노출 카운터를 저장한다. sidecar의 별도 `provenance`에는 현재 상태 종류, 원본 native ID, 상대 발화 노출·업데이트·외국어 복습 버퍼 수를 기록하고 실제 payload와 대조한다. 새 실험은 `kind="native"`를 명시적으로 요구하고 텐서 로딩/RunStore 생성 전에 acquisition 파일을 거부한다. 학습 후 상태의 복원은 acquisition 파일을 명시적으로 요구하는 `restore`/`resume` 경로만 사용한다.

모국어 이해 검사는 별도 native 물체 쌍의 네 문형 모두를 사용한다. 생성 검사는 그 장면에서 허용한 네 원어 표현 중 하나를 정확히 생성했는지 판정한다. 엄격한 유한 문장 집합의 검사이며 일반적 의미 동치·자연스러움 평가가 아니다. 평가에 쓰는 고정 발화도 시작 전에 같은 기준으로 감사한다. 실패한 문항을 골라 버리지 않고, 하나라도 감사에 실패하면 실행을 분석 부적격으로 표시한다.

## 자료 분할과 사전검사

세계는 색 3개×모양 3개인 물체 9종, 서로 다른 두 물체의 순서 2개×관계 2개로 총 144개 장면을 가진다. 방해 보기는 같은 두 물체의 순서·관계만 다르므로 단어 존재 여부만으로 풀 수 없다.

신경망 모드는 무순서 물체 쌍 단위로 **학습 / L1 적격성 검사 / 첫 접촉 사전검사 / 곡선 측정 / 독립 최종 평가**를 나눈다. 기본은 56/16/24/24/24장이다. 보기 이미지도 해당 분할에만 속한다. L1 훈련과 만남 후 학습은 학습 분할만 사용한다. 최종 평가는 학습이 끝난 뒤 한 번만 실행한다. 곡선 문항은 체크포인트마다 반복하지만 가중치·optimizer·복습 자료를 변경하지 않는다. 평가 전후 실제 학습 상태 해시가 달라지면 실패 처리한다.

사전검사 포함 기준은 점 추정치가 우연과 유의하게 다르지 않다는 검정이 아니다. `chance_margin`은 **원정답률 단위**의 사전 허용 폭이다. 기본 우연 구간은 0.25±0.15다. 같은 물체 쌍의 네 문항이 상관되므로, 각 물체 쌍의 평균을 하나의 [0,1] 표본으로 두고 Hoeffding 구간을 사용한다. 각 방향 반폭은 `sqrt(log(80)/(2*m))`이며 m은 쌍 수다. 두 방향에 Bonferroni를 적용한 가족 포함률은 독립 쌍 표집 가정 아래 최소 95%다. 양쪽 구간 전체가 허용 폭 안에 있어야 `primary`다. 아래 끝이 상한보다 높으면 `positive_baseline_extension`, 부족한 정밀도는 `uncertain`이다. L1/출처/고정 발화 검사를 못 넘으면 `ineligible`이다.

이 작은 세계는 표본 쌍 수가 적어 **기본 구간으로 우연 수준의 동등성을 확정할 수 없다**. 이것은 장치 파일럿의 한계다. 본실험의 1차 조건을 실제로 충족하려면 의미 세계·독립 사전검사 표본을 늘리고 검정력과 반복 수를 먼저 설계해야 한다. 작은 표본의 Wilson 구간만으로 0을 입증했다고 표시하지 않는다. 그림 유무나 인공언어 실험을 필수 선행 과제로 바꾸지는 않는다.

현재 기본 사전검사 24문항은 독립 쌍 6개라 반폭이 약 0.604다. 설정 상한 96문항도 24쌍/반폭 약 0.302다. 현재 공식과 허용 폭 0.15를 유지하면 가장 이상적인 중심 0.25에서도 최소 98개 독립 쌍이 필요하다. 따라서 본실험 준비의 완료 조건은 **충분한 L1 숙련도 통과 모델 확보와 의미 세계·사전검사 표본·설정 상한의 함께 확대**다. 설정만 바꿔 primary 판정을 얻거나 구간을 임의로 약화하는 것으로 대체하지 않는다.

## 누적 업데이트, 대조 조건, 재개

공유 장면에서 고정된 자기 언어 생성기로 두 발화를 먼저 만든다. 각 수신자는 상대 문장과 **실제로 함께 본 그림**을 사용해 L1 이해 가중치를 업데이트한다. 다른 순서·관계의 세 장면을 시각적 방해 보기로 받으며 정답 의미 JSON·파트너 번역·내부 벡터·gradient는 받지 않는다. 그림의 표현은 자기 쪽 고정 픽셀 모듈이 계산한다.

`acquisition_profile`은 Adam 학습률, 노출당 업데이트 수, 업데이트당 자기 언어/과거 외국어 복습 수, 버퍼 크기를 고정한다. 자기 언어 복습과 외국어 재생 노출량은 주 노출량과 구분한다. 평가는 복습 버퍼에 들어가지 않는다. 수신자의 추론은 대화 기록 검색이 아니라 학습한 가중치를 사용한다.

대조 조건은 `updates_per_exposure=0`, `association="shuffled"`, `reset_l1_understanding=true`다. 무작위 연결은 발화마다 원래 그림과 다른 학습 장면을 시드로 뽑으며, 실제 발화 그림과 학습에 사용한 그림을 모두 로그에 남긴다. 대조 실행에는 원래 적격성 분류도 보존하면서 별도 `control` 표지를 붙인다. 한국어/영어 학습자의 일본어 점수가 반드시 달라야 검사에 통과하도록 만들지 않는다. 검사는 같은 입력을 처리할 때 실제 L1 이해 가중치에 역전파가 도달함을 확인한다.

체크포인트에는 양쪽 전체 가중치, optimizer, L1/외국어 복습 버퍼, 난수 상태, 노출·업데이트 카운터를 저장한다. 두 파일이 모두 저장된 뒤 마지막 완전한 체크포인트 포인터를 공개한다. `resume`는 **새 실행 폴더**에서 그 지점의 두 학습자를 복원하고 원래 고정 발화·분할·계획·평가 이력을 이어간다. 저장 지점 뒤 미완료 작업은 다시 실행한다. 이전 로그는 유지한다. 라이브 평가 결과와 가중치가 연속 실행과 일치하는지 자동 검사한다. CPU 결정성을 사용하며 다른 PyTorch/하드웨어 버전 간 bitwise 동일성까지 보장하지 않는다.

## 이해도, 방향, 노출량

원정답률 p와 우연 보정값 q를 모두 저장한다.

`q = (p - 1/K) / (1 - 1/K)`, K=4이면 `q = (p - 0.25) / 0.75`.

p=0.25이면 q=0, p=1이면 q=1이다. 음수는 잘라내지 않는다. 보정 정의는 `chance-correction-v1`, 보기 수는 `choice_count`에 남긴다. 문항별 우연 확률이 달라지면 새 평가 버전이 필요하다.

기존 schema 1의 90% 목표는 **원정답률**로 유지한다. `evaluation_profile.threshold_scale="corrected"`를 명시한 경우에만 보정값 기준을 사용한다. 4지선다의 보정 90%는 원정답률 92.5%다. 대시보드 곡선은 원정답률로 통일하고 보정값은 별도 열·라벨로 표시하며 목표선도 원정답률로 변환한다.

`Tτ(B|A)`는 모국어 A 화자가 언어 B 이해도 τ에 도달하는 노출량이다. UI의 `A → B`는 **A의 발화를 B가 이해**한다는 의미다. 결과에는 `learner_native_language`, `target_language`, `speaker_language`를 명시해 방향을 보존한다.

주 단위는 공유 장면 1회 + 각 수신자의 상대 발화 1개다. 실행에는 대화·발화 수, 장면 제시/고유 장면 수, 각 수신자의 문자·바이트·입력 unit 수, 업데이트 수, L1/외국어 복습량, 학습 sequence unit 수, 시간과 계산량 대용치를 저장한다. 계산량 대용치는 `6 * 이해 모듈 매개변수 수 * 학습 sequence unit 수`이며 실측 FLOPs가 아니다. 연구용 연산 비교에는 별도 profiler가 필요하다.

## 목표 도달량과 곡선 비교

0회부터 같은 조기 종료 조건을 적용한다. 최초 단일 통과, 연속 통과 시작, 연속 통과 확인을 구분한다. 평가 간격 사이의 정확한 도달 시점은 알 수 없다. 완료 상한까지 미도달이면 도달량 `null`, `threshold_outcome="right_censored"`로 둔다. 실패·취소·실행 중은 별도 상태다. 도달 실행만의 중앙값은 조건부 통계이며, 미도달 비율과 실패/취소 수를 함께 남긴다.

기존 `normalized_auc_observed`는 실제 관측 종료 시점까지의 기술적 평균이다. 종료 시점이 다른 실행의 동등 노출 비교에 사용하지 않는다. `common_horizon`을 사전에 정하면 그 지점의 고정 노출 정확도와 해당 구간의 정규화 AUC를 별도로 제공한다. 구간을 끝까지 관측하지 못했으면 결측이며 외삽하지 않는다. `compare_common_auc`는 같은 완전 관측 구간·척도가 아니면 거부한다. 곡선 비교의 기본 신경망 예시는 조기 종료를 끈다.

문항 Wilson 95% 구간은 화면의 기술적 보조치다. 독립 모델 반복의 불확실성·사전검사 포함 구간과 다르다. 반복 probe와 연구자의 사후 선택에 따른 불확실성도 이 구간이 해결하지 않는다.

## 모델·경험 반복과 확장

본실험 전에 [개발 전용 진단](development-diagnostics.md)의 `diagnose-native`와 `plan-screening`을 사용할 수 있다. 작은 train/dev 학습 진단과 현재 판정식의 가정별 포함 확률을 기록하지만, 이 출력은 본실험에서 제외한다. 세계·모델 용량·허용 폭·평가 발화 출처를 자동 확정하거나 변경하지 않는다.

`grid`는 **모델 프로파일 C × 독립 모델 반복 R × 경험 반복 D × L(L−1)/2**개의 양방향 쌍을 만든다. 언어 4개는 6쌍·12방향이다. 기본 C=1, R=2, D=2이면 24실행·48개 방향 곡선이다. 크기만으로 지능을 정의하지 않고 모국어 성취도를 같이 기록한다.

한 모델 반복 안에서는 언어별 초기 가중치·의미 범위·L1 예산을 대응시킨다. 다른 반복은 실제로 다른 초기화와 L1 표본 순서로 다시 학습한다. 경험 반복은 원본 L1 모델에서 새로 시작하며 장면 순서·평가 보기 시드를 바꾼다. 현재 grid는 같은 장면 분할을 유지한다. 분할까지 바꾸려면 해당 분할로 L1 모델을 다시 준비한 별도 계획을 실행한다.

목표 언어를 고정하고 모국어를 바꿀 때는 같은 목표 L1 생성 체크포인트와 같은 그림·발화 스트림을 사용한다. 모든 쌍/경험은 원본 L1 체크포인트를 새로 역직렬화한다. 다른 쌍에서 배운 외국어 상태가 넘어가지 않는다. 체크포인트의 언어·구조·토크나이저·L1 프로파일·독립 모델 반복·훈련 분할이 다르면 거부한다.

실행 전 `grid-plan`으로 작업 목록·업데이트 예산을 확인한다. `grid.json`에는 pending/running/completed/failed/cancelled를 구분하며 중단 후 미실행 작업을 계속할 수 있다. 실패/취소 항목을 자동으로 성공으로 덮어쓰지 않는다. 집계는 모델 프로파일과 포함 분류를 나누고 모델별 경험 곡선을 보존한다. 대화 반복을 독립 모델로 세지 않으며 pooled 경험으로 신뢰구간을 자동 생성하지 않는다. 연구 반복 수는 파일럿 변동과 자원으로 정해야 한다.

## 참고한 선행 설계

- [Deep Learnability (2020)](https://www.frontiersin.org/journals/artificial-intelligence/articles/10.3389/frai.2020.00043/full): 모국어 훈련 경험을 거친 모델로 학습 가능성을 비교하는 배경.
- [Emergent Translation in Multi-Agent Communication (2018)](https://arxiv.org/abs/1710.06922): 공동 시각 환경의 발화로 학습 신호를 만드는 배경. 이 구현은 별도 빈 외국어 encoder 대신 L1 이해 모듈을 재사용한다.
- [ByT5 (2022)](https://aclanthology.org/2022.tacl-1.17/): 바이트 기반 처리의 참고. 공개 다국어 사전학습 가중치를 사용하는 것은 아니다.

이 구현의 성능을 해당 논문의 재현 결과로 주장하지 않는다. 현재 검증된 것은 제한된 세계에서의 학습·저장·측정 경로이며, 충분한 L1 숙련도와 초기 우연 조건을 갖춘 본실험 결과는 아직 확보하지 않았다.
