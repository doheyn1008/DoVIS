# 파일럿 프로토콜과 해석 범위

## 연구 질문과 현재 구현

원래 질문은 초기 상호 이해도가 낮은 언어 쌍을 목표 이해도까지 필요한 대화·학습량으로 구별할 수 있는지다. 이 저장소는 그 질문을 바로 입증하지 않고, 노출량과 이해도 곡선을 일관되게 수집하는 장치를 제공한다.

현재 측정값은 **정해진 학습자·초기 지식·시각 과제·대화 규칙·평가 방식 아래의 습득 비용**이다. A 사용자가 B를 배우는 비용과 B 사용자가 A를 배우는 비용을 따로 기록한다. 대칭성이나 삼각부등식을 가정하지 않으므로 수학적 거리라고 주장하지 않는다. 학습량으로 거리를 정의한 뒤 가까운 언어가 빨리 학습된다는 결과만으로 타당성을 검증해서는 안 된다.

## 과제·분할·평가

색 3개 × 모양 3개인 물체 9종에서 서로 다른 두 물체를 골라 왼쪽/위쪽에 놓는다. 무순서 물체 쌍 36개마다 순서 2개 × 관계 2개로 총 144개 장면을 만든다. 기본 설정은 물체 쌍의 25%를 평가로 분리해 학습 108장, 평가 풀 36장이다. 그중 기본 24문항을 선택한다.

각 문항의 네 보기는 같은 두 물체의 순서·관계만 다르다. 따라서 색·모양의 존재 여부를 맞히는 것만으로는 네 보기 중 하나를 특정할 수 없다. 정답 위치는 방향별 문항 집합 안에서 균등하다. 두 방향은 같은 장면과 보기 순서를 사용한다.

원어 발화는 시작 전에 각 화자의 초기 상태로 생성한다. 이후 평가에는 고정된 발화를 사용하므로 두 에이전트가 새로운 암호에 합의해 과제만 해결하는 현상과 원래 언어에 대한 수신 능력을 일부 구분한다. 생성된 문장이 실제 원어이고 장면을 정확히 설명하는지는 별도 검토해야 한다. 대화 중 언어 변화 자체를 자동 탐지하지는 않는다.

평가용 이미지·발화·정답은 실험 제어기가 보유한다. 실제 endpoint 학습자는 PNG와 발화만 받는다. 장면 의미 JSON, 정답 인덱스, 의미가 들어간 파일명은 전달하지 않는다. 평가 호출에는 정답 그림을 단독으로 보여주지 않고 네 보기 이미지를 보여준다. 평가를 학습 기록에 추가하지 않으며 전후 상태 해시가 바뀌면 실행을 실패로 처리한다. 원격 서버의 숨은 학습 상태는 클라이언트가 검사할 수 없으므로 서버가 무상태 추론이라는 운영 조건이 필요하다.

## 두 실행 모드

| 모드 | 화자 | 수신자의 학습 | 해석 |
| --- | --- | --- | --- |
| `demo` | 자기 언어의 고정 템플릿 | 완전한 시각 특징과 발화의 unigram·bigram·단어 위치를 연관시키는 누적 naive Bayes | 실행 장치 검증. 실제 자연어·인간·신경망 습득 결과가 아님 |
| `endpoint` | 로컬 VLM의 자기 언어 생성 | 가중치 고정, 최근 `context_exchanges`개 상대 발화와 공유 이미지로 문맥 내 적응 | 해당 모델·기록 예산·과제 조건의 파일럿 결과 |

데모 수신자는 상대 언어의 사전을 조회하지 않는다. 하지만 시각 특징을 완벽히 안다는 강한 가정과 제한된 문장 템플릿을 사용한다. 영어·한국어·일본어 표기는 자연어 전체가 아니라 각 언어로 작성한 통제 문장 집합을 뜻한다. 문장 토큰화·길이·형태가 점수에 직접 영향을 주므로 데모의 언어 조합 순위에 언어학적 의미를 부여하지 않는다.

endpoint 모드에서는 상대 언어를 모른다고 가장하도록 지시하지 않는다. 모국어로 발화하라는 지시는 초기 외국어 능력을 제거하지 않는다. 토크나이저, 시각 인코더, 사전학습 자료에 들어 있던 언어 지식도 확인해야 한다. 다국어 VLM을 연결하면 장치 시험에는 유용하지만 순수한 제2언어 초기 습득 조건은 아니다. 같은 체크포인트의 두 호출을 독립적으로 단일언어 학습한 두 모델로 취급해서도 안 된다.

## 노출량과 종료 규칙

대화 1회는 새 공유 그림 한 장과 각자 자기 언어로 말하는 발화 두 개다. 둘 모두 상대 발화 하나를 경험하므로 누적 수신 노출량도 각각 1 증가한다. 먼저 말하는 쪽을 교대한다. 학습 장면은 시드로 섞은 순서에서 비복원 추출하며, 한 바퀴 후 다시 섞는다. 실제 모델의 두 번째 발화는 첫 발화를 입력받아 반응할 수 있다.

대화 0회에서 먼저 평가하고, 설정한 간격 및 마지막 대화에서 평가한다. 90%는 문항 정답률이지 한 발화의 의미를 90% 설명했다는 뜻이 아니다. 기본 설정은 연속 두 체크포인트에서 90% 이상인 경우 목표 달성을 확인한다. 최초 단일 통과 시점, 연속 통과 시작 시점, 확인 시점을 나눠 기록한다. 평가 간격 사이의 정확한 도달 시점을 관측했다고 주장하지 않는다.

기본 조기 종료는 두 방향 모두 기준을 확인한 경우다. 각 방향의 도달 정보는 별도로 남긴다. 마지막까지 기준을 확인하지 못하면 도달량은 결측(`null`), 우측 중도절단(`right_censored`)과 관측 종료량을 함께 기록한다. 상한을 도달값으로 대체하거나 미도달 실행을 삭제하지 않는다. 서버 오류·사용자 중단은 별도 실행 상태이며 완료된 미도달 실행과 구분한다.

## 불확실성과 반복

문항별 정확도에는 Wilson 95% 구간을 표시한다. 이것은 개별 문항 수준의 기술적 구간이며 물체 쌍 내 문항의 상관, 평가 반복, 체크포인트 선택, 생성 모델의 변동을 모두 반영한 연구 수준 신뢰구간이 아니다. 24문항 만점도 불확실성이 남는다. 목표 통과 판정은 정확도 점수에 적용하며 신뢰구간 하한에 적용하지 않는다.

고정된 probe의 반복 사용은 학습 경로를 비교하기 위한 것이다. 동일 모델의 상태를 평가 호출로 갱신하지 않지만 연구자가 결과를 보고 설정을 반복 조정하면 평가 집합에 대한 적응이 생길 수 있다. 논문에는 별도의 독립적인 최종 평가와 필요시 물체 쌍 또는 실행 단위의 불확실성 분석이 필요하다.

시드는 데이터 분할·대화 순서·보기 순서·데모 동점 처리를 재현한다. endpoint 서버의 토큰화·추론 구현·비결정성까지 통제하지는 않는다. 시드 반복에서는 분할도 달라지므로 데이터 표본에 의한 변동과 생성 변동을 분리해 해석해야 한다. sweep의 도달 중앙값은 도달 실행에 한정되며 미도달 비율과 같이 제시한다.

## 연구 결과로 해석하기 전에 남은 결정

- 단일언어 초기화의 근거와 모국어 숙련도의 비교 가능성
- 문맥 내 적응과 매개변수 학습 중 실제 연구에서 채택할 방식
- 실제 언어 쌍과 장면 범위, 문장 정확성·자연어 유지 검사
- 제한된 그림 선택 점수가 사용자가 원한 발화 해석·설명과 얼마나 일치하는지
- 노출량을 대화 수 이외에 문자·토큰·시각 정보량으로도 통제할지
- 본실험의 평가 간격·반복 수·상한과 독립적인 최종 평가
- 반복 안정성, 다른 모델로의 전이, 독립적인 인간 학습 성과 예측 등 척도의 타당성 검증

이 구현은 위 결정을 확정한 것으로 취급하지 않는다.
